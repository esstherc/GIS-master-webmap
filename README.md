# GIS Master's Programs in the US

An interactive web map for exploring GIS master's programs across the United States.

This project is designed for prospective students, educators, and researchers who want to compare graduate GIS programs by location, program type, format, duration, graduation requirement, and official program information.

Live map: https://yanbingchen.site/GIS-master-webmap/

## 2026 Data Update

The October 2026 inventory includes **176 master's program records across 142 institutions**.

The 2026 update reviewed current university websites and catalogs, added newly identified programs, removed sunset programs, updated outdated links, and refined program names where needed.

For the full annual update record, see [`change records/2026_change_summary.md`](change%20records/2026_change_summary.md).

## Main Features

- Explore U.S. GIS master's programs on an interactive map.
- Filter programs by state, program type, format, and school or program title.
- Open program popups with degree name, location, format, duration, graduation requirement, and official links.
- Save programs to a personal shortlist in the browser.
- Add personal notes to saved programs.
- Compare two to four saved programs side by side.
- Download saved programs as a CSV file.
- Suggest edits or missing programs through the website.
